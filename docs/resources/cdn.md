# qrator_cdn (Resource)

Manages a CDN configuration for a domain in Qrator.

## Example Usage

```terraform
resource "qrator_cdn" "example" {
  domain_id     = 12345
  cache_control = "cdn"
  http2         = true

  access_control_allow_origin = ["https://(www\\.)?example\\.com"]

  cache_query_params = {
    mode   = "ignore"
    params = ["utm_source", "utm_medium"]
  }

  redirect_code = 301

  client_headers   = ["X-Custom-Header:value"]
  client_ip_header = "X-Real-IP"
  upstream_headers = ["X-CDN-Service:Qrator"]

  content_compression = {
    gzip    = ["text/html", "text/css", "application/javascript", "application/json"]
    br      = ["*"]
    deflate = []
    zstd    = []
  }

  tls_versions = ["TLSv1.2", "TLSv1.3"]

  cache_errors = [
    {
      code    = 502
      timeout = 60000
    }
  ]

  access_filter = {
    skip_ips = ["203.0.113.0/24"]

    geo    = { deny = ["CN"], deny_status_code = 451 }
    method = { allow = ["GET", "HEAD", "POST"], allow_status_code = 405 }

    uri = {
      allow             = ["^/api/", "^/static/"]
      allow_status_code = 404
      deny              = [{ regex = "^/api/internal/", status_code = 404 }]
    }

    user_agent = {
      deny        = [{ regex = "^BadBot", status_code = 429 }]
      block_empty = true
    }
  }

  webp = 80
}

output "cdn_default_host" {
  value = qrator_cdn.example.default_host
}
```

## Content compression

`content_compression` lists, for each algorithm (`gzip`, `br`, `deflate`, `zstd`), the MIME types that CDN compresses with it. All four algorithms must be listed:

- `["*"]` — compress any MIME type (the Qrator default for every algorithm);
- `["text/html", "application/json"]` — compress only these MIME types;
- `[]` — the algorithm is disabled.

When `content_compression` is omitted, Terraform neither reads nor changes the setting. Removing it from the configuration stops managing the setting and leaves it unchanged in Qrator.

`content_compression` replaces `compress_disabled` (removed in v0.5). An algorithm listed in `compress_disabled` corresponds to an empty set in `content_compression`, e.g. `compress_disabled = ["br"]` is equivalent to:

```terraform
content_compression = {
  gzip    = ["*"]
  br      = []
  deflate = ["*"]
  zstd    = ["*"]
}
```

## Access filter

`access_filter` decides whether the CDN serves a request or blocks it with an HTTP status code. Requests from `skip_ips` bypass all filters. The other sections are applied in this order, and the first one that blocks a request determines the response:

1. `ip` — client IP address
2. `geo` — client country
3. `method` — HTTP method
4. `uri` — requested URL
5. `user_agent` — `User-Agent` header
6. `referer` — `Referer` header

Each section can have:

- a **deny list**: a request matching an entry is blocked. In `ip`, `geo` and `method` all entries share `deny_status_code`; in `uri`, `user_agent` and `referer` every entry carries its own `status_code`, and entries are checked in the listed order: the first matching entry determines the response code. Keep the more specific patterns first;
- an **allow list**: when it is not empty, a request matching none of the entries is blocked with `allow_status_code`.

If a status code is not set, CDN responds with `403`.

### Managed and unmanaged filter

- When `access_filter` is set, Terraform owns the **whole** filter: every section that is not described is cleared on `terraform apply`, including rules added in the Qrator dashboard. `access_filter = {}` removes all rules.
- When `access_filter` is omitted, Terraform neither reads nor changes the filter, so it can be managed in the dashboard.
- Removing `access_filter` from the configuration stops managing the filter; the rules stay in Qrator as they are.

### Value formats

- IP addresses and networks must be written in canonical form (`8.8.8.0/24`, not `8.8.8.1/24`; `2001:db8::/32`, not `2001:DB8::/32`). The network prefix must be `/14` or longer.
- Country codes are ISO 3166-1 alpha-2 in upper case (`CN`, `US`); `A1`, `A2` and `O1` are also accepted.
- HTTP methods are written in upper case: `CONNECT`, `DELETE`, `GET`, `HEAD`, `OPTIONS`, `PATCH`, `POST`, `PUT`, `TRACE`.
- Status codes (`deny_status_code`, `allow_status_code` and `status_code` of regex deny entries): 200–599, except 204, 300–308, 407, 426 and 511.
- Lists hold at most 500 entries (HTTP method lists at most 9).

## Import

CDN configuration can be imported using the domain ID:

```shell
terraform import qrator_cdn.example 12345
```

The access filter and content compression settings are not imported. If the configuration contains `access_filter` or `content_compression`, the first plan after the import shows them being added, and `terraform apply` writes them to Qrator.
